Transitions — Quick Reference

The six logical relationships and the signals for each

Type 1

Contrast

however, although, despite, while, yet, in contrast, on the other hand, nevertheless, nonetheless

Type 2

Cause & Effect

therefore, as a result, consequently, thus, hence, so, for this reason

Type 3

Example / Illustration

for example, for instance, specifically, in particular, to illustrate

Type 4

Addition

furthermore, in addition, moreover, additionally, also, besides

Type 5

Similarity

similarly, likewise, in the same way, just as

Type 6

Concession / Qualification

admittedly, granted, to be sure, of course, it is true that — used before a point you acknowledge before rebutting

Syra's Method

1
Read both sentences fully before choosing. The transition connects two complete ideas. You cannot choose the right signal if you only read one sentence.
2
State the relationship in your own words. "The first sentence says X. The second says Y. The relationship is: Y contrasts with X / Y results from X / Y is an example of X." Match your relationship to a transition type.
3
Eliminate by logic, not familiarity. "However" is not always the answer to a contrast question — "despite," "nevertheless," or "yet" might be equally correct. Eliminate any transition that signals the wrong relationship type first.
Top Traps
"However" as default answer
Confusing concession with contrast
Confusing addition with cause-effect
Reading only the second sentence
