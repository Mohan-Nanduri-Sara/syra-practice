Working with Functions — SAT Reference

Core rules you must know cold before moving to the next topic

Key Facts

Function evaluationf(a) means substitute a for x, then simplify
Composite functionf(g(x)): evaluate the INNER function first
f(x) + k vs f(x + k)+k outside shifts UP; +k inside shifts LEFT
Inverse functionswap x and y, then solve for the new y
Average rate of change[f(b) − f(a)] ÷ (b − a)
Zero of a functionthe x-value(s) where f(x) = 0
Composite Order

Inner function first, always

f(g(x)) means: evaluate g(x) first, then plug that RESULT into f. f(g(3)) and g(f(3)) are usually different values.

Transformations

Inside vs. outside the parentheses

f(x) + k shifts the graph UP by k (affects output). f(x + k) shifts the graph LEFT by k (affects input) — the direction flips from what the sign suggests.

Inverse Functions

Undo the operations in reverse order

To find f⁻¹(value), set f(x) equal to that value and solve for x — don't evaluate f at that value directly.

Rate of Change

It's just slope between two points

Average rate of change over [a, b] is identical to finding the slope of the line through (a, f(a)) and (b, f(b)).

Multiplying a Function

Scale the OUTPUT, not the input

g(x) = k·f(x) means: find f(x) first, then multiply the result by k. Don't multiply x by k before evaluating f.

Watch Out For
Evaluating f(g(x)) and g(f(x)) as if they give the same result
Confusing f(x) + k (shift up) with f(x + k) (shift left)
Evaluating f at the target value instead of solving for the inverse
Stopping at an intermediate value (like x²) instead of finishing the solve
