Trigonometry — SAT Reference

Core rules you must know cold for the trig unit

Key Facts

SOH-CAH-TOAsin=opp/hyp, cos=adj/hyp, tan=opp/adj
45-45-90 triangleleg : leg : hypotenuse = 1 : 1 : √2
30-60-90 triangleshort leg : long leg : hypotenuse = 1 : √3 : 2
Degrees ↔ radiansradians = degrees × (π/180)
Pythagorean identitysin²θ + cos²θ = 1
Complementary angle identitysin(θ) = cos(90° − θ)
SOH-CAH-TOA

Always identify opposite/adjacent relative to the angle

"Opposite" and "adjacent" depend on WHICH angle you're using — the same triangle gives different ratios depending on which acute angle is θ.

Special Right Triangles

Memorize the exact side ratios

45-45-90 and 30-60-90 triangles show up constantly — knowing their side ratios cold saves you from redoing the Pythagorean theorem every time.

Angle of Elevation

Draw the right triangle first

The horizontal distance, the vertical height, and the line of sight form a right triangle — tan(angle) = height ÷ horizontal distance.

Trig Values Don't Depend on Triangle Size

Only the angle matters, not the side lengths

sin(30°), cos(30°), etc. are FIXED values — they don't change based on how big the triangle is. A given hypotenuse length is often irrelevant extra information.

Two-Point Elevation Problems

Set up a system using both angles

When two observation points give two different angles of elevation to the same object, write a tangent equation for each point and solve the resulting system.

Watch Out For
Mixing up which side is "opposite" vs. "adjacent" for the angle in question
Confusing the 45-45-90 ratio (×√2) with the 30-60-90 ratio (×√3, ×2)
Treating irrelevant given values (like a stated hypotenuse) as necessary for a fixed-angle trig calculation
Forgetting that sin and cos are both negative in the third quadrant
