Perpendicular linesnegative reciprocal slopes
Linear Growth

Adds the same amount every step

A linear function changes by a constant DIFFERENCE per unit of x — the same amount is added (or subtracted) each time.

Exponential Growth

Multiplies by the same factor every step

An exponential function changes by a constant RATIO per unit of x — the previous value is multiplied by the same factor each time, not added to.

Growth/Decay Rate

Read the rate straight from the base

In y = a(1 + r)ˣ, the growth rate is r as a percent. In y = a(1 − r)ˣ, the decay rate is r as a percent — don't confuse the base itself with the rate.

Slope From Standard Form

Rearrange to slope-intercept first

For Ax + By = C, the slope is −A/B. It's safer to solve for y first than to memorize the shortcut under time pressure.

Perpendicular Slopes

Flip AND negate

A slope perpendicular to m is −1/m — both flip the fraction and change the sign. Forgetting either half of that gives a wrong answer.

Watch Out For
Treating exponential growth like linear growth (adding instead of multiplying)
Reading the base (1 + r) as the rate itself instead of solving for r
Forgetting to both flip and negate the slope for a perpendicular line
Mixing up simple growth with compounding across multiple periods
