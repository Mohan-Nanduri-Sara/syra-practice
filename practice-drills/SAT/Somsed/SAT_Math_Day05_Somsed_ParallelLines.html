4x + 6y = 10 and 8x + 12y = 15 — describe the solution set
  1. Coefficient ratio: 4/8 = 6/12 = 1/2 (matches)
  2. Constant ratio: 10/15 = 2/3 (does NOT match 1/2)
  3. Same slope, different line ⇒ no solution
  4. The graph should show two parallel lines, never touching
